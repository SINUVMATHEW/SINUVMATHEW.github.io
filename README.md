# Sinu V Mathew — Portfolio

The React portfolio lives at the root of this folder. The previous static site is preserved in `old-SINUVMATHEW.github.io/` as the source archive for earlier writing and media.

## Run locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Structure

- `src/` — React application and visual system
- `public/legacy-assets/` — media migrated from the original portfolio
- `old-SINUVMATHEW.github.io/` — untouched original website
